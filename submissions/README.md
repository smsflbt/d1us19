# Gönderiler

Öğrenci cevapları, Worker servisi tarafından bu klasörün altında
tarih bazlı alt klasörlerde saklanır:

```
submissions/
  2026-11-20/
    125-ayse-yilmaz-1732000000000.json
    126-mehmet-demir-1732000005000.json
```

Her dosya bir öğrencinin gönderisidir (kimlik bilgileri, 3 senaryonun
cevapları ve öğretmenin verdiği puanlar/notlar).

> Bu klasörü elle düzenlemeyin; puanlama öğretmen panelinden yapılır
> ve Worker dosyaları otomatik günceller.
